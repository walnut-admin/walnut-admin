## 项目说明

Walnut Admin 是一个**完全开源**的全栈 TypeScript monorepo，前端和后端代码均在 GitHub 公开。你可以自由使用、修改、分享，用于学习或个人/商业项目。

## 最后

国内中后台模板已经很饱和了，有一些优秀的开源项目比 Walnut Admin 更成熟。但这个项目是我入行以来一直想完成的事——从三个独立仓库到 monorepo，从前端为主到真正的全栈，每一步都在学习和成长。

后续也计划在 B 站做一些分享视频，聊聊架构设计的思考和踩过的坑，希望能帮到同样在摸索的人。

如果你觉得这个项目对你有帮助，给个 Star 就是最好的支持。
